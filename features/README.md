# Executable feature files

Feature files are the executable requirements and behavioral backlog. Requirement identity, scope, status, and acceptance criteria live in the `*.feature` files; this page does not maintain a duplicate inventory.

For system architecture, current capabilities, limitations, verification scope, and roadmap, see [ARC42](../ARC42.md). Requirement traceability is maintained in [Appendix A](../docs/arc42/appendix-requirements.adoc).
