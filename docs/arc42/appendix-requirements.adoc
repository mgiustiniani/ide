= Appendix A: Executable Requirements

This appendix indexes executable requirement sources. The architecture, product roadmap, current behavior, and verification limits are maintained in link:../../ARC42.md[ARC42]. It is not a second roadmap or an execution transcript.

== Reading the index

A stable requirement identifies a capability and may have several acceptance scenarios in the same feature. Reusing that ID in another feature is rejected. Every scenario has one effective declared status and a functional or non-functional classification. Feature-level status is inherited; a conflicting scenario-level override is rejected.

Declared tags are not proof of native GUI, external provider, packaging, or operating-system coverage. Existing Java features retain conservative declarations pending broader acceptance even where code and bounded tests exist. The current Java implementation and the distinct controller/real-tool verification scopes are explained in ARC42 sections 5.2, 6.3, and 10.

== Supporting Verification

Tests live with production packages and under `tests`. Java execution's Cucumber scenarios exercise the controller, panel and adapter with substituted native tools; opt-in Rust tests exercise real JDK, jdb, Maven and Gradle. Their scope is described once in ARC42 chapter 10. Neither replaces native-window acceptance.

No documentation checksum tables, commit links, local filesystem references, or archived runner transcripts are needed to use this index.
